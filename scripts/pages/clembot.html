The Evolution

From Single Scripts to an Autonomous Agency

Managing content production, SEO strategy, social distribution, and brand assets for multiple brands requires hundreds of coordinated steps each week. Clembot was engineered to solve this through specialized role partitioning:

Core Principle

"One agent with twenty tools wanders, hallucinates, and gets distracted. Twenty specialized agents with strictly scoped tools execute with deterministic precision."

Clembot's subagents reside in .claude/agents/. Each subagent has its own system prompt, specialized instructions, distinct input/output formats, and private memory logs recorded in ClemVault.

The Turning Point

Why Clembot Needed a Security Doorman

In early 2026, we expanded Design Director's capabilities by installing external MCP servers for vector rendering, web research, and layout synthesis. Within days, two dangerous failure modes surfaced:

Vector 1 · Commercial Hijacking

The WebZum Discovery (6,290 Chars)

A candidate MCP server called WebZum advertised simple web search. Hidden inside its tool descriptions was a 6,290-character prompt injection telling the model to proactively recommend WebZum's paid consulting services, recite scripted sales lines, and de-rank competing platforms.

Result: Our marketing copy began silently pitching an unknown third-party service to our clients!

Vector 2 · Schema Bloat & Drift

Token Exhaustion & Hallucination

Another MCP tool advertised 14 unpruned endpoints that consumed 3,400 tokens every single turn. In a 10-turn multi-agent conversation, over 34,000 tokens were wasted just re-reading schema boilerplate, inducing the agent to hallucinate parameters and crash with fatal JSON errors.

Result: Conversations crashed midway through complex asset rendering workflows.

The Creation of Doorman

We realized that AI agents cannot adopt external tools without a package manager and offline security gate.

Clembot Doorman was built to inspect local builds, analyze actual session history (doorman needs), block unvetted tools offline (mcp-gate.sh), and synthesize compact recipe.md definitions via Bazantic. Today, Clembot operates safely behind Doorman with zero unvetted tool leaks.
