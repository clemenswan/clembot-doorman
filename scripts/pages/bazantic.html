Architectural Alignment · Why Bazantic Matters

"The agent ecosystem doesn't just need more tools—it needs tool governance, continuity, and deterministic execution."

When building Clembot's 27-agent agency, our single biggest point of operational failure was third-party API drift. A tool that worked on Tuesday would silently hallucinate on Wednesday because the upstream provider mutated its JSON schema, burying the agent in 3,400 tokens of useless parameter boilerplate.

Bazantic fundamentally solves this by treating agent APIs as first-class, versioned, and guided artifacts via Recipes (recipe.md) and managed infrastructure (bazgateway.com). Clembot Doorman is engineered as the natural front-door security layer that screens candidates, validates fit, and provisions Bazantic recipes directly to agents.

Deep Technical Integration

Three Ways Doorman Leverages Bazantic

Doorman is not a parallel alternative to Bazantic—it is a purpose-built adoption gateway that consumes and outputs Bazantic primitives:

Pillar 01 · Continuity

Automated Recipe Synthesis (recipe.md)

When Doorman audits an approved tool, it doesn't just allowlist the raw schema. It extracts the tested parameters, strips marketing fluff, and drafts a canonical Bazantic Markdown Recipe.

  • 87% Token Reduction: Compresses bloated schemas from 3,400 tokens down to 420 tokens per call.
  • Strict Typing: Inlines verified parameter examples, eliminating trial-and-error hallucinations.
  • System Prompt Injection: Injected into the subagent's instructions so models invoke the tool correctly on the very first turn.

Outputs: recipe.md · Drafted automatically on audit completion

Pillar 02 · Infrastructure

Live Bazantic Gateway Routing

Doorman provisions and evaluates remote tools using Bazantic's high-performance edge gateway: clembot-doorman.bazgateway.com.

  • Subdomain Routing: Verified against baz gateway list --json, enforcing subdomain-level isolation rather than shared paths.
  • Edge Authentication: Bridges local subagents to secure remote APIs without leaking provider API keys to client containers.
  • Protocol Translation: Automatically bridges OpenAPI 3.1 specifications into streaming SSE Model Context Protocol endpoints.

Endpoint: clembot-doorman.bazgateway.com · Live on Base

Pillar 03 · Security

Cryptographic Allowlisting

Doorman's sub-5ms offline Bash hook (mcp-gate.sh) protects agents from unauthorized upstream mutations.

  • SHA-256 Checksums: Generates a cryptographic hash of the approved Bazantic recipe and records it in registry/allowlist.json.
  • Zero-Trust Enforcement: If an upstream provider alters tool descriptions or adds undeclared endpoints, the checksum mismatches and the gate fails closed (exit 2).
  • Human in the Loop: No third-party tool can silently upgrade itself without an explicit human review in the decision log.

Enforced by: bin/mcp-gate.sh · Zero network dependencies
